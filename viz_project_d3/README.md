### Files in the solution:

myD3app.js: 
- code related to visualizations on the page that appears when clicking on
"I solemnly swear that I am up to no good"

smallMultiples.js:
- code related to the small multiples, that appear when clicking on "development >"

donutchart.js:
- code that deals with the visualizations on the pages that are related to particular character

index.html:
- `.html` of the very first page with the "I solemnly swear..." text

charts.html:
- `.html` of the page to which the user is redirected when
pressing "I solemnly swear..." button

developmentStats.html:
- `.html` of the page containing small multiples

rest of the .html:
- `.html` for corresponding pages for top 5 characters who spoke the most

### How to run the solution:
- after opening the project in visual studio, run in terminal in the `./final_project` command `node index.js`
- open new `google chrom` tab and write `localhost:3000`
